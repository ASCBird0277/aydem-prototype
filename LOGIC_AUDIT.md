# AYDEM route and learning-logic audit

## Intended learner paths

### First-time path

Home → Module 1 identification → result → account screen → Module 2 download/open → Module 3 screen tour → Module 3 lessons 2–5.

### Revisit path

Home cards, sidebar module links, the Module 3 five-lesson navigator, Glossary links, and Safe Practice must all remain available. A revisit must not force the learner to restart the course or enter an unrelated exercise.

## Findings and decisions

| Area | Finding | Decision |

## Approval gate

The routing correction is ready for review. The device visuals are not fully approved until each platform has a current, privacy-safe capture that matches the learner’s actual screen. Do not solve that gap with a made-up universal view.
